# VOIDGUARD v0.3.4 — CORE STABILITY

Исправляющий релиз для совместимости PowerShell 5.1/7, полноты сканирования и безопасности защитных операций. Новых автоматических удалений не добавлено.

## Исправлено

- Исправления коллекций и меню встроены в Scanner и UI. Stability больше не подменяет чужие функции во время запуска.
- Quick Scan и Custom Scan отдельно возвращают `FilesDiscovered`, `FilesScanned`, `FilesSkipped`, `FilesFailed` и `FileErrors`.
- Ошибки перечисления и обработки файлов не скрываются. При неполном проходе, нулевом количестве обработанных объектов или достижении лимита выдаётся `PARTIAL`.
- Перед восстановлением из карантина сверяются размер и SHA-256, проверяются идентификатор, метаданные, конфликт назначения и защищённые системные пути.
- Reparse points и символические ссылки в файловых и родительских каталогах блокируются при защитных операциях.
- Pending Ledger различает ожидание перезагрузки, проверенное удаление, сохранившийся файл и ошибки верификации.
- Встроенный `voidguard.core` проверяется по закреплённым в коде каталогу, метаданным, файлам и SHA-256.
- При `WhatIf` отложенное удаление не регистрируется.

## Добавлено

- Регрессионные тесты для поддельных rule packs, повреждённого карантина, пограничных результатов сканирования и проверок времени загрузки Windows.
- Актуальная документация по сканированию, карантину, rule packs и статусам Pending Ledger.

## Проверка

GitHub CI проверяет PowerShell 7 и Windows PowerShell 5.1, режимы CLI, синтаксис, выпуск архивов и новые регрессионные сценарии. Релиз создаётся после слияния проверенной ветки.

## Установка

1. Скачайте `VoidGuard-v0.3.4-Portable.zip` из GitHub Releases.
2. Распакуйте архив в новую папку. Не смешивайте модули разных версий.
3. Запустите `VoidGuard.cmd`.
4. Для диагностики выполните:

```powershell
.\VoidGuard.ps1 -Mode SelfTest -Professional -NoAnimation -Json
```

## Безопасность

VoidGuard не заменяет Defender и не гарантирует обнаружение всех угроз. Утилита блокирует системные, Microsoft-signed, WRP, TrustedInstaller и reparse-point цели; для изменяющих операций требуется подтверждение пользователя.
