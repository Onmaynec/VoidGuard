# VOIDGUARD v0.5.0 — THREAT INTELLIGENCE

Версия добавляет два практических инструмента: безопасное обслуживание подписанных rule packs и сбор диагностических данных в локальный Incident Bundle. Прежнее сканирование, карантин, System Integrity и Defender Offline сохранены.

## Signed Rule Updates

- Предпросмотр подписанного пакета из локальной папки: ID, версия, издатель, ключ и список файлов.
- Проверка RSA-SHA256 через локальный trust store и SHA-256 каждого файла; отказ при неподписанном, изменённом, нестандартном или слишком большом пакете.
- Повторная проверка после копирования файлов перед установкой.
- Замена только подписанного пакета с тем же издателем и ключом при переходе на более новую версию.
- Сохранение предыдущей версии, список истории, откат по History ID.
- Отдельное подтверждение включения или отключения правил в активном движке.
- Встроенный core pack защищён от замены через обновления.

## Incident Bundle

- Подготовительный просмотр категорий перед записью ZIP.
- Стандартные данные: сводка Microsoft Defender/Firewall, инвентарь правил, находки процессов, persistence и записи pending.
- Опции: сканирование выбранного пути, System Integrity diff и до 100 метаданных событий Defender Operational за последние 7 дней.
- По умолчанию скрываются сырые пути, командные строки, сетевые адреса, имя компьютера и сообщения событий.
- Полный сбор персональных сведений возможен только через явный флаг IncludeSensitive.
- В ZIP входят diagnostics.json, manifest.json и SHA256SUMS.txt. Архив создаётся локально без сетевых запросов и без перезаписи существующего файла.
- Ошибки отдельных источников сохраняются как PARTIAL; программа не объявляет такой архив полным.

## Интерфейс и CLI

В главном меню появились THREAT INTELLIGENCE / RULE PACKS и INCIDENT BUNDLE / EVIDENCE. CLI поддерживает RuleUpdate, RuleHistory, RuleRollback, RuleActivate, IncidentPreview и IncidentExport.

## Проверки

CI тестирует механизмы на PowerShell 5.1 и PowerShell 7, включая отрицательные случаи: модифицированные файлы, неправильную подпись, неучтённые файлы, отказ от подтверждения, WhatIf и попытку перезаписи ZIP.

## Установка

Скачайте VoidGuard-v0.5.0-Portable.zip из GitHub Releases. Распакуйте в отдельную папку и запустите VoidGuard.cmd.

Файл Rules/trusted-publishers.json в проекте изначально пустой. Новые signed packs не могут быть установлены без независимой проверки и ручного добавления доверенного публичного ключа издателя.

## Безопасность

Нет автоматической загрузки правил по сети, отправки Incident Bundle или удалённого анализа файлов. Перед пересылкой ZIP просмотрите его содержимое: даже стандартный диагностический отчёт может содержать технические сведения об установленном программном обеспечении.
