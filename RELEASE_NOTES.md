# VOIDGUARD v0.3.2 — СТАБИЛЬНОЕ МЕНЮ

Исправляющий релиз устраняет падение сразу после стартовой анимации и выравнивает череп строго по центру относительно надписи VOIDGUARD.

## Исправлено

- устранена ошибка `Error formatting a string: Index (zero based) must be greater than or equal to zero and less than the size of the argument list`;
- номер, маркер выбора и подпись пункта меню теперь передаются оператору форматирования `-f` единым массивом аргументов;
- добавлена проверка пустого списка пунктов меню с понятным сообщением вместо необработанного исключения;
- стартовый череп центрируется по реальной видимой ширине рисунка и ширине ASCII-логотипа;
- при расчёте границ учитываются обычные пробелы и символ Braille Blank `U+2800`, используемый в файле черепа;
- сохранена форма рисунка: обрезаются только общие внешние пустые поля, а внутренние отступы строк не меняются.

## Проверки

- добавлены отдельные регрессионные тесты форматирования меню и центрирования блока;
- тесты выполняются в PowerShell 7 и стандартном Windows PowerShell 5.1;
- CI проверяет, что исправленная функция действительно установлена внутри области модуля интерфейса;
- сборка Portable и Source ZIP по-прежнему проверяется через Windows PowerShell 5.1.

## Установка

1. Скачайте `VoidGuard-v0.3.2-Portable.zip` из раздела Releases.
2. Распакуйте архив в новую папку.
3. Запустите `VoidGuard.cmd` от имени администратора.

Пользователям `v0.3.1` рекомендуется заменить всю распакованную папку, чтобы гарантированно получить новый модуль исправления консоли и обновлённые тесты совместимости.

> Сканер, rule packs, YARA, карантин и защитные ограничения remediation в этом релизе не ослаблялись и не изменялись.
