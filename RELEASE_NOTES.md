# VOIDGUARD v0.4.0 — SYSTEM INTEGRITY

В новой версии добавлены локальные снимки Windows, сравнение изменений и безопасный запуск Microsoft Defender Offline.

## System Baseline
- Настройки Microsoft Defender, Firewall, UAC, SmartScreen, прокси и исключения антивируса.
- Службы: режим запуска, исполняемая команда, учётная запись и тип.
- Планировщик: задания, действия, аргументы, триггеры, Enabled.
- Автозапуск: Run/RunOnce и Startup folders.
- SHA-256 и размер выбранных файлов. Hosts включён по умолчанию.
- Снимки хранятся в локальном JSON schema v1 и не перезаписываются.

## Baseline Diff
- Типы изменений ADDED, REMOVED, CHANGED, исходные и новые значения.
- Проверка структуры JSON, уникальности ключей и совпадения компьютера.
- При ошибках сбора PARTIAL: неполный раздел не сравнивается, отсутствующие данные не трактуются как удаление.

## Microsoft Defender Offline
- Проверка Windows, прав администратора, WinRE, Defender и BitLocker.
- Безопасный предпросмотр и два обязательных подтверждения запуска.
- VoidGuard не изменяет BitLocker/WinRE и не включает сканирование автоматически.
- Запуск может немедленно перезагрузить Windows; результат доступен в Protection history.

## Тестирование
На PowerShell 5.1 и 7 проверяются создание baseline, его сравнение, повреждённые и неполные данные, безопасность предпросмотра Defender Offline и прежние CLI-режимы. Реальный Start-MpWDOScan в CI не запускается.

## Установка
Скачайте VoidGuard-v0.4.0-Portable.zip, распакуйте в новую папку и запустите VoidGuard.cmd. Не смешивайте файлы разных версий.

## Ограничения
System Integrity не заменяет антивирус. Baseline не подписан криптографически; храните доверенную копию отдельно и не публикуйте её без проверки конфиденциальных данных.
