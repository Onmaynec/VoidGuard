# VOIDGUARD v0.3.3 — МАКСИМАЛЬНАЯ СТАБИЛЬНОСТЬ

Этот исправляющий релиз устраняет набор ошибок, которые проявлялись при запуске разных разделов VoidGuard через стандартный Windows PowerShell 5.1. Вместо проверки только стартового экрана добавлен полный прогон реальных режимов программы.

## Исправлено

- `PERSISTENCE MATRIX` больше не завершается ошибкой `Argument types do not match`;
- Custom Scan корректно обрабатывает один найденный файл и больше не падает из-за отсутствующего свойства `Count`;
- пустые результаты `Processes`, `Pending` и `Locks` возвращаются как валидный JSON-массив `[]`;
- Quick Scan и Custom Scan используют совместимые с PowerShell 5.1 массивы и `Generic.List.ToArray()`;
- восстановлена команда загрузочной полосы интерактивного Quick Scan;
- ошибка одного пункта меню больше не закрывает всю программу: сообщение показывается пользователю, после чего меню продолжает работу;
- сбой проверки pending ledger при старте больше не мешает открыть интерфейс;
- JSON-ошибки CLI теперь содержат тип исключения, позицию и стек вызовов.

## Добавлено

- модуль `VoidGuard.Stability.psm1` для совместимости и защиты интерактивного режима;
- пункт меню `SYSTEM SELF-TEST`;
- CLI-режим `SelfTest`;
- отдельные stability-тесты для PowerShell 7 и Windows PowerShell 5.1;
- полный регрессионный прогон в настоящем `powershell.exe` 5.1;
- автоматическая проверка генерации автономных JSON и HTML reports.

## Что проверяет CI

Успешно запускаются:

- `SelfTest`;
- `Status`;
- `Processes`;
- `Persistence`;
- `Pending`;
- `RulePacks`;
- `QuickScan`;
- `CustomScan`;
- `Locks`;
- `Yara`;
- безопасный dry-run remediation;
- генерация JSON и HTML reports;
- визуальная демонстрация;
- сборка и запуск релизных архивов через Windows PowerShell 5.1.

## Установка

1. Полностью удалите ранее распакованную папку VoidGuard.
2. Скачайте `VoidGuard-v0.3.3-Portable.zip` из раздела Releases.
3. Распакуйте архив в новую папку.
4. Запустите `VoidGuard.cmd` от имени администратора.
5. При необходимости выполните самопроверку:

```powershell
.\VoidGuard.ps1 -Mode SelfTest -Professional -NoAnimation -Json
```

Не копируйте новые файлы поверх `v0.3.1` или `v0.3.2`: смешивание версий модулей может вернуть уже исправленные ошибки.

> Защитные ограничения карантина и remediation не ослаблялись. VoidGuard по-прежнему блокирует системные, Microsoft-signed, WRP, TrustedInstaller, reparse-point и критические процессные цели.
